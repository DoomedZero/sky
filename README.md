and do your work, all with suppport of single key shortcuts!
no unwanted bloat on UI, rather a mountain of features that are just so hard to ignore.

### Shortcut Keys

##### Home Page

1. S - Sun
2. C - Create clouds (only after sun menu is opened)
3. i - to focus in input field
4. Esc - to stop focus from input field
(You have to escape from input fields to use enter and delete)
5. Enter - to save or change cloud
6. Delete - to delete cloud

##### Canvas Page

1. H - Go to home
2. T - create text box
S, i, Esc work as home page

### Features 

1. A calm sky where you create workspace pointer(icon) / clouds.
2. Your clouds are stored persistently in local browser storage.
3. Give name to clouds, change thier name, delete them, all with keyboard.
(Clicks can work too but KEYBOARD!!)
4. Each cloud opens a workspace / sky where you actually work.
5. Create TextCloud (Textbox) , edit it, move it.
